# Issue 595 — deployment provenance

The Controller projects separate repository, publication, Controller deployment,
agent deployment, recipe installation, runtime load and physical acceptance
boundaries. The Fleet **Deployment evidence** disclosure and
`vonkctl fleet provenance --json` consume the same typed endpoint. Human command
output includes exact recipe/image identities and per-rank evidence state.

## Evidence sources and limits

Normal operation needs no GitHub request and no Docker socket. Agent, installed
recipe, model, build and run evidence come from Controller persistence. A package
hash is unknown unless a successful authenticated upgrade receipt matches the
currently reported binary and build. The library authority row records the latest
successful sync receipt, not a failed import's candidate commit.

`VONK_DEPLOYMENT_OBSERVATIONS_FILE`, when configured, contains the sole current
schema-2 `DeploymentObservations` contract. Repository/publication observations
are collected outside API requests; absent observations remain unknown. Configured
malformed data fails visibly. Publication comparison reports identity difference,
not inferred commit ancestry or runtime failure. A publication observation must
come from verified publication evidence; desired Compose configuration cannot
establish a running image digest. Root integration adds baked Controller source
metadata while actual running image identity remains unknown unless observed.

Physical receipts are trusted local physical-lane evidence, separately supplied
through this typed observation source. Catalog validation reports, CI outcomes,
installation completion, start success and readiness are never promoted into a
physical receipt. No physical hardware exercise or live deployment was performed.

Root integration owns application/auth registration, generated OpenAPI/Python/TS
clients, CLI parser/emit hookups and baked Controller build metadata. Run integrated
contract/client compilation and the command against the registered endpoint after
those shared changes land.
