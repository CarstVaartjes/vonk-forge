| Bounded retry and history | Existing distribution retry limits remain, with stale failure observations fenced to their original checkpoint. Preflight has at most three attempts per node/phase, one pending child, and bounded exact per-node receipts; stale evidence cannot become a successful empty state. Transient exhaustion and repeated-host-change tests pass. |
| Cancellation and shared artifacts | New administrator cancel API records idempotent durable intent. Queued work cancels immediately. An attached shared preparation/transfer child may finish; its successful receipt is retained and the parent stops before the next phase. Current shared child identity does not establish exclusive ownership, so cancellation does not revoke shared cache/build authorization or delete content. Startup/active runtime cancellation requires explicit Stop. Cancellation/restart/cache-retention and API tests pass. |
| Honest resumable progress | NAS download completion no longer marks Spark copying complete. Aggregate transfer byte counters remain separate from phase ETA. Fleet and Library use the same measured progress component. |
