# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository's issues, pull requests and discussions, and
wherever someone represents the project.

Be kind and constructive, assume good intent, and keep the discussion on the
work. Harassment, insults and personal attacks are not accepted.

To report unacceptable behaviour, open the **...** menu on the comment, issue
or pull request and choose **Report content** (or use **Report abuse** on a
user's profile); GitHub reviews those reports. Report a security problem
privately through the repository's **Security** tab, as
[SECURITY.md](SECURITY.md) describes. The maintainer may edit or remove
content, or block a participant, as the Covenant's enforcement guidelines
describe.
